# Product vision

Manage.kar is a **local-first personal workspace** for tasks, notes, habits, and focus.

It is **not** a recruiting platform, candidate profile store, resume engine, or multi-user ERP. Those concepts appear in some agent templates and in leftover UI copy. Repository evidence does not support them.

## Who it is for

One person who wants a calm place to capture work and keep it after refresh — without an account, cloud vendor, or fake team dashboard.

## Problem

People lose trust in productivity tools when:

- work disappears after a refresh or sync failure
- export is a lie
- the UI pretends AI, teams, or Google sync exist

That is the current user pain in this repository, and it matches 2026 market complaints about data loss and pricing/privacy in cloud task apps.

## Destination

A personal, honest PWA:

1. Capture a task, note, habit, or voice thought.
2. See it immediately.
3. Still see it after reload.
4. Export / import the same document the UI uses.
5. Optional later: encrypted device sync. Not required for v2.

## What we will not become

- A Notion clone with ten fake modules
- A collaboration suite without a backend
- An AI product that invents “peak hours”
- A candidate / job-search OS unless the owner explicitly changes the product
